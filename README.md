# nexora

A modern Next.js starter project with TypeScript, Tailwind CSS, Prisma, and PostgreSQL support.

## Getting started

1. Install dependencies:
   npm install
2. Copy the environment file:
   cp .env.example .env
3. Update `DATABASE_URL` in `.env` for your PostgreSQL instance.
4. Run database setup:
   npm run db:push
5. Start the app:
   npm run dev

Open http://localhost:3000
